# Licences

## ORC License

`ORC_License.pdf` is the authoritative text, committed exactly as published —
unaltered bytes, SHA-256 `ad8b60dc2c4345a2e9fbf978720f6a5f7e1ebad1329fd563f48e648d7da6cde4`.

**There is deliberately no plain-text transcription.** This PDF has broken
internal character spacing, and every extraction method produces corrupted
text: words run together (`useLicensed`), pronouns split (`Y ou`), and in
places letters drop entirely (`Noce` for `Notice`). A licence that looks
authoritative while being subtly wrong is worse than no copy at all, so the
PDF stands on its own.

The licence is also on record with the Library of Congress at **TX 9-307-067**
and published online, which is the canonical reference the required notice
points to.
